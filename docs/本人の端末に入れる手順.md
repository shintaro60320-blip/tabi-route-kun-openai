# 旅ルートくん（OpenAI版）をスマホに入れる手順（約 5 分）

この版は、持ち主（とと）の OpenAI を使ってルートを作ります。使う人がキーを作ったり、お金を払ったりする必要はありません。
先に とと が「金庫番」を置いておく必要があります（`金庫番の置き方.md`）。

Gemini 版（`tabi-route-kun`）とは別のアプリです。同じスマホに両方入れても、設定や記録は混ざりません。

持ち物：スマホ、アプリの URL、とと から聞いた「金庫番の住所」と「合言葉」。

## 1. アプリをホーム画面に置く
1. アプリの URL（`https://shintaro60320-blip.github.io/tabi-route-kun-openai/`）を開く。
2. Android：右上「⋮」→「アプリをインストール」（または「ホーム画面に追加」）。
   iPhone：Safari の共有ボタン →「ホーム画面に追加」→「追加」。
3. ホーム画面に「旅ルートAI」が出る。

## 2. 住所と合言葉を入れる
1. 「旅ルートAI」を開く → 右上の歯車。
2. 「金庫番の住所」と「合言葉」を入れる（とと から LINE 等で受け取って貼り付ける）。
3. 「つながるか確かめる」→「つながります（モデル：…）」と出れば完了。

## 3. お試し
1. 「もどる」→ 行き先に「大阪城」→「おすすめを出す」→「半日」→「このコースで出す」。
2. ルートが出たら 1 か所目を押す → 「Googleマップ 写真・口コミ」でマップアプリが開く。

## 本人に伝えること
- 料金と時間は**目安**。行く前にお店の営業を確かめてください。
- 1 日に作れる回数に上限があります。「上限に当たりました」と出たら明日また使えます。
- 合言葉は**人に教えない**でください（持ち主の OpenAI が使われます）。

## 困った時
| 画面の文言 | すること |
|---|---|
| インターネットにつながっていません | 電波のある所で「もう一度」 |
| 合言葉が違うようです | 設定で入れ直して「つながるか確かめる」 |
| 金庫番につながりませんでした | 住所を入れ直す。続くなら とと に知らせる |
| 今日使える回数の上限か、OpenAI の利用の上限に当たりました | 明日また使う。続くなら とと に知らせる |
| うまく作れませんでした | 「もう一度」。続くなら行き先の言い方を変える |
| 見つかりませんでした | 行き先を変える（例：大阪城 → 大阪城公園） |
| Wikipedia が混み合っていて… | 1 分ほど待ってから「もう一度」 |
