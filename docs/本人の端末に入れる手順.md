# 旅ルートくん（OpenAI版）を本人のスマホに入れる手順（とと が一緒にやる・約 15 分）

持ち物：本人のスマホ、本人の OpenAI アカウント（無ければ作る）、残高に入れるお金（クレジットカード）、アプリの URL。

Gemini 版（`tabi-route-kun`）とは別のアプリです。同じスマホに両方入れても、キーや記録は混ざりません。

## 1. 本人の OpenAI のキーを作る（本人のアカウントで）
※ アプリの設定画面にも「キーを作るページを開く」のボタンと同じ手順が出ます。
1. ブラウザで `https://platform.openai.com/api-keys` を開き、本人のアカウントでログイン（無ければ作る）。
2. 「Create new secret key」→ 名前（例：旅ルート）を入れて作る。
3. できたキー（`sk-…`）の「Copy」を押す。**この画面でしか表示されない**ので、閉じる前にアプリへ貼る。
   - **画面を撮ったり、人に送ったりしない。** キーは本人の名義。とと は手順を手伝うだけで、キーを控えない。
4. 残高（クレジット）を入れる：`https://platform.openai.com/settings/organization/billing/overview` で、最初は少額（5 ドル程度）でよい。
   - **OpenAI には無料の枠がありません。** 残高が無いと「利用の上限に当たりました」と出て使えません。
   - 料金の見込み：1 回のルート作成でおよそ 0.1 円（`gpt-6-luna` の場合・2026-11-17 の公式料金から計算した見込み）。

## 2. アプリをホーム画面に置く
1. アプリの URL（`https://shintaro60320-blip.github.io/tabi-route-kun-openai/`）を開く。
2. Android：右上「⋮」→「アプリをインストール」（または「ホーム画面に追加」）。
   iPhone：Safari の共有ボタン →「ホーム画面に追加」→「追加」。
3. ホーム画面に「旅ルートAI」が出る。

## 3. キーを貼る
1. 「旅ルートAI」を開く → 右上の歯車 → 「OpenAI のキー」の欄を長押し →「貼り付け」。
2. 「キーを確かめる」→「使えます（モデル：…）」と出れば完了。
3. 「文字の大きさ」は本人に見てもらって「大きい」にしてもよい。

## 4. お試し
1. 「もどる」→ 行き先に「大阪城」→「おすすめを出す」→「半日」→「このコースで出す」。
2. ルートが出たら 1 か所目を押す → 「Googleマップ 写真・口コミ」でマップアプリが開く。
3. 「地図」→「Googleマップで案内を始める」→ 区間を選ぶ → 経路が出る。

## 本人に伝えること（3 つだけ）
- 料金と時間は**目安**。行く前にお店の営業を確かめてください。
- 使った分だけ OpenAI の残高から引かれます。「利用の上限に当たりました」と出たら残高を確かめてください。
- 設定画面のキーは**人に見せない**でください（見られると、本人の残高を使われます）。

## 困った時
| 画面の文言 | すること |
|---|---|
| インターネットにつながっていません | 電波のある所で「もう一度」 |
| キーが正しくないようです | 設定で貼り直して「キーを確かめる」 |
| OpenAI の利用の上限に当たりました | 残高を確かめる・少し待ってからもう一度 |
| うまく作れませんでした | 「もう一度」。続くなら行き先の言い方を変える |
| 見つかりませんでした | 行き先を変える（例：大阪城 → 大阪城公園） |
| Wikipedia が混み合っていて… | 1 分ほど待ってから「もう一度」 |
| 声の入力が使えません | 文字で入れる |
